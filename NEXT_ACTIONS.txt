COMPLETED — P1 real executor behind the orchestrator boundary (2026-11-13 15:05 UTC)
Result: `backend/app/execution.py` implements `LocalProcessExecutor`: a bounded, allow-listed, shell-free subprocess runner for commands named in each project's `.aatm/exec.json`. Execution is opt-in (`AATM_EXECUTION_ENABLED`) and `POST /orchestrator/run` returns 409 when it is off. 21 new tests (backend 220 → 241). Verified live over HTTP: one task ran a real command, completed with its actual output recorded, and released its lease.
Two real defects were found while building it and would otherwise have shipped silently: cancellation could never reach a running task (the orchestrator held a write transaction across the run, so the cancel write failed with `database is locked`; fixed by committing the claim first plus SQLite WAL), and `expire_on_commit=False` left `cancel_requested_at` stale so a stopped task stayed `running` forever (fixed with an explicit refresh).
Still open by design: no provider call is made, so a task runs a local command, not a model. Wiring an authorized, consented model call remains P0.
