# AATM API

FastAPI + SQLAlchemy application with file-backed SQLite as the no-setup local default. From this directory, create an environment and install `requirements.txt`, then run `uvicorn app.main:app --host 127.0.0.1 --port 8000`. The manager record is an unconfigured identity only; no AI calls or task execution occur in this foundation build.

Run tests from this directory with `python -m pytest`.
